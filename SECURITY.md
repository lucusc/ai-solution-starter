# Security policy

## Supported version

The `main` branch is the only supported line while the project has no published
releases.

## Report a vulnerability

Do not open a public issue containing vulnerability details.

Use the repository's private vulnerability-reporting option when it is
available. If the option is unavailable, contact the repository maintainers
through an established private channel and include only the minimum information
needed to coordinate a secure report.

Do not attach:

- credentials, tokens, certificates, or connection strings;
- tenant, subscription, account, or private-network identifiers;
- real documents or customer data;
- production database records; or
- unsanitized logs.

General setup questions and non-security defects belong in the repository's
normal support path. This policy does not promise a specific response or
resolution time.
