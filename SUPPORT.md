# Support

Use repository issues for reproducible defects and usage questions about the
starter. Include:

- the affected component;
- expected and actual behavior;
- sanitized reproduction steps;
- tool versions;
- the exact validation command that failed; and
- a minimal error message with identifiers removed.

Never post credentials, tokens, tenant or subscription IDs, private endpoints,
real documents, customer data, or unsanitized logs.

Azure subscription access, billing, quota, regional capacity, and platform
incidents should be handled through the appropriate Azure support channel.
This repository does not provide production support or a service-level
agreement.

Report security vulnerabilities through [SECURITY.md](SECURITY.md), not a
public issue.
